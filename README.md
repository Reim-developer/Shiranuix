# Shiranuix

A simple text editor with its own document format.

Shiranuix opens ordinary `.txt` files and its own `.shiranux` documents —
text kept with the alignment and typography that goes with it. It carries
its own file tree beside the page, works entirely offline, and runs on
Windows, Linux and macOS.

## Install

Every [release](https://github.com/Reim-developer/Shiranuix/releases/latest)
ships one self-contained archive per machine: unpack it and run `Shiranuix`,
with no runtime to install first. `SHA256SUMS.txt` on the same page carries
every archive's hash.

| Machine | Archive |
| --- | --- |
| Windows | `Shiranuix-X.Y.Z-win-x64.zip`, `...-win-arm64.zip` |
| Linux | `Shiranuix-X.Y.Z-linux-x64.tar.gz`, `...-linux-arm64.tar.gz` |
| macOS | `Shiranuix-X.Y.Z-osx-x64.tar.gz`, `...-osx-arm64.tar.gz` |

## What it does

- Ordinary `.txt` files open as they are, and every file's line endings
  leave the way they came.
- Its own `.shiranux` documents hold text with paragraph alignment and
  typography beside it.
- A file tree down the left of the page: browse, open, make, rename,
  delete, open another folder.
- Plain text in, plain text out — the files stay readable without this
  program, now and later.
